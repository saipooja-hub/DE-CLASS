*Encapsulation:
--Encapsulation is about protecting data inside a class.
--It means keeping data (properties) and methods together in a class, while controlling how the data can be accessed from outside the class.
--This prevents accidental changes to your data and hides the internal details of how your class works.

*class variable vs instance variable:

class variable:
--class variables are shared by all instances of a class and are used for data common to all objects.

Instance variable:
--instance variables are unique to each object and are used for data that changes from one instance to another.

*Instance method:

Instance methods take the argument self and can therefore access all instance variables and methods like self.name, and also all class variables and methods like self.alias here.

They can only be used on instances and not on the class directly. 

*class method:

Instance methods take the argument cls and can therefore access all class variables and methods like cls.alias, but no instance variables/methods.

Use this when you don't need to access variables that belong to an instance, but still need general attributes that belong to the class.

*Static methods:

Static methods can neither access class variables/methods nor instance variables/methods. They behave like plain (global) functions except that you can call them from an instance or the class.

Data class in python:
 regular class designed primarily to store data, minimizing repetitive "boilerplate" code.a regular class designed primarily to store data, minimizing repetitive "boilerplate" code. Introduced in Python 3.7 via the dataclasses module, it uses a @dataclass decorator to automatically generate common methods like __init__(), __repr__(), and __eq__().

from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

point = Point(2, 3)
print(point) # Output: Point(x=2, y=3)
print(point == Point(2, 3))
